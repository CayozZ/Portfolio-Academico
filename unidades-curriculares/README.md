# Unidades curriculares

Atividades organizadas por disciplina. Algumas disciplinas pedem trabalhos aplicados diretamente ao Projeto Integrador, nesses casos o arquivo fica em [`../projeto-integrador/`](../projeto-integrador/) e esta pasta só aponta para ele, para não duplicar conteúdo.

| Disciplina | Status | Observação |
|---|---|---|
| [`gestao-da-informacao/`](gestao-da-informacao/) | Em andamento | A maior parte das entregas foi aplicada ao PI |
| [`empreendedorismo-e-planos-de-negocio/`](empreendedorismo-e-planos-de-negocio/) | Em andamento | Customer Discovery aplicado ao PI |
| [`governanca-em-ti/`](governanca-em-ti/) | Em andamento | Estudo de caso, não ligado ao PI |
| [`verificacao-e-validacao/`](verificacao-e-validacao/) | Em andamento | Testes funcionais e orientados a dados |
| [`inteligencia-artificial/`](inteligencia-artificial/) | Em andamento | Artigo acadêmico em repositório próprio |
| [`tech-english/`](tech-english/) | Em andamento | Seminário em inglês |
